The `platform` directory is platform specification. It tells Roc which Modules and functions are available and maps the Roc function names to the host functions written in Rust.
The modules are written in Roc and only the functions in the `Host` module are implemented in the host language. The `main.roc` file provides these mappings.

#### platform/main.roc

- `requires`: which functions the App has to provide for the platform to work.
- `exposes`: The modules the platform exposes to the App
- `packages`: packages the platform needs
- `provides`: exposes a roc function to the host (i.e. the rust code can call that roc function)
- `hosted`: maps Roc function declarations to native symbols implemented by the host, so Roc code can call them. These are all the host functions that roc actually calls

## Tracking Sleep

Module is in `platform/Sleep.roc`, the only hosted function is `Host.sleep_nanos!`. This function is also used in the Durations modules.
The `sleep_nanos!` function can be found in the Host module but also in `main.roc`.
The `main.roc` maps the `Host.sleep_nanos!` to `hosted_sleep_nanos`. A declaration of the `hosted_sleep_nanos` function can be found in the `src/roc_platform_abi.rs` which is autogenerated glue code. The actual implementation can be found in `src/lib.rs`. It is marked as `pub extern "C"` so it adheres to the C ABI calling conventions expected by the Roc compiler. It has also the `#[no_mangle]` annotation so the function name stays and the linker can find it.

## Startup

```
OS starts executable
└─ native runtime startup
   └─ main(argc, argv)                         Rust — src/lib.rs
      └─ rust_main(argc, argv)                 Rust — src/lib.rs
         │
         ├─ Initialize host:
         │    create RocHost
         │    register host pointer and current thread
         │
         ├─ Prepare arguments:
         │    collect process arguments
         │    separate argv[0] as program name
         │    convert remaining arguments into RocList<OsStr>
         │
         ├─ Install panic hook for terminal cleanup
         │
         └─ roc_main(args_list)                native symbol → compiled Roc
            └─ main_for_host!(args)            Roc — platform/main.roc
               └─ main!(args)                 Roc — YOUR application
```
